# Mega Survivors

Прототип игры в духе **Vampire Survivors** для Android с упором на карту и
экипировку (вдохновлено **Megabonk**), но с классическим видом сверху.

Чистый Kotlin + `SurfaceView`/`Canvas` — без игровых движков и внешних
зависимостей. Спрайты героев, монстров и объектов — из тайлсета
**Dungeon Crawl Stone Soup** (лицензия CC0/public domain, взято с
opengameart.org), эффекты и снаряды процедурные. Проект открывается
в Android Studio как есть.

## Версии

Каждый пуш в ветку собирает новый APK с номером версии `0.2.<номер сборки>`
(виден при установке и в главном меню игры). Скачивается со страницы
GitHub Actions, артефакт называется `mega-survivors-v0.2.N`.

## Что уже есть

**Меню и мета-прогресс**
- Главное меню: выбор оружия, стартового предмета и до 2 фолиантов перед забегом.
- 14 оружий; новые открываются за золото, которое копится между забегами.
- Золото зарабатывается убийствами и исследованием карты, остаток забега
  уходит в копилку.


**Ядро выживания**
- Вид сверху, ландшафтная ориентация, плавающий виртуальный джойстик
  (касание в любом месте экрана).
- 14 видов оружия: дротики, клинки, аура огня, молния, коса, морозная
  аура, ответный вихрь (контратака при уроне), ядовитые ножи, судный час
  (зачистка экрана), банан-бумеранг, пси-клинки (пробивают линию),
  метеоры, дробовик, клинок жажды (урон растёт с убийствами).
  До 20 уровней прокачки, до 4 оружий одновременно.
- **Эволюции**: оружие 20 ур. + предмет-катализатор = супероружие.
  Морозная аура + Морозный куб → Ледяная буря; Яд + Сердце чумы →
  Чумное облако; Коса + Тёмный серп → Жнец.
- Враги 5 типов (ходок, бегун, громила, танк, элита) с ростом сложности
  по минутам. Элита появляется раз в минуту и всегда дропает шмотку.
- Кристаллы опыта, уровни, экран выбора «1 из 3» (оружие/пассивки).
- 8 пассивных навыков: урон, скорость атаки, бег, здоровье, броня,
  магнит, область атак, опыт.

**Карта (главный акцент)**
- Ограниченный мир 8400×8400 с границей; вся карта видна на миникарте
  (сундуки, шрайны, статуи, золото, элита).
- **Сундуки** разбросаны по карте — открываются за золото, цена растёт
  с каждым открытым. Внутри предметы 5 тиров.
- **Кучки золота** — награда за исследование карты.
- **Шрайны** трёх видов — стой в круге 5 секунд, чтобы захватить:
  - *Шрайн ярости* — +60% урона, +25% области (35 c);
  - *Шрайн ветра* — +35% скорости, +45% скорости атаки (35 c);
  - *Шрайн камня* — +80% брони, +25% HP, +50% магнита (45 c).
- **Статуи предков** — захват 9 секунд, дают **постоянный** +5% ко всем
  навыкам до конца забега.
- Пока идёт захват — на точку стягиваются волны врагов.

**Предметы и фолианты (Megabonk-стиль)**
- 25 предметов пяти тиров: обычный / необычный / редкий / мистический /
  легендарный. Пул настраивается весами в `Items.kt`, со временем забега
  шансы высоких тиров растут.
- Спец-эффекты: вампиризм, реген, уклонение, катализаторы эволюций.
- 8 фолиантов — пассивные усиления на весь забег, выбираются в меню.

## Сборка

Нужен Android Studio (или Android SDK + JDK 17):

```bash
cd android-game
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Либо просто открыть папку `android-game` в Android Studio и нажать Run.
Минимальная версия Android — 7.0 (API 24).

## Структура кода

| Файл | Что делает |
| --- | --- |
| `Game.kt` | Ядро симуляции: враги, оружие, опыт, захват точек, состояния |
| `World.kt` | Чанковая генерация карты: сундуки, шрайны, статуи |
| `Items.kt` | Генератор экипировки: слоты, редкости, статы |
| `Weapons.kt` | Баланс оружия по уровням |
| `Upgrades.kt` | Пул апгрейдов для экрана левел-апа |
| `Stats.kt` | Характеристики и баффы |
| `Entities.kt` | Игрок, враги, снаряды, подбираемое |
| `Renderer.kt` | Вся отрисовка: мир, сущности, HUD, оверлеи |
| `Joystick.kt` | Виртуальный джойстик |
| `GameView.kt` | Игровой цикл и ввод |

## Идеи на потом

- Мета-прогресс между забегами (валюта, разблокировка персонажей).
- Больше оружия и эволюции (комбо оружие + пассивка).
- Боссы на 5/10 минут, событийные зоны на карте.
- Звук и вибрация, спрайты вместо процедурной графики.
