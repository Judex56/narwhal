# Mega Survivors

Прототип игры в духе **Vampire Survivors** для Android с упором на карту и
экипировку (вдохновлено **Megabonk**), но с классическим видом сверху.

Чистый Kotlin + `SurfaceView`/`Canvas` — без игровых движков и внешних
зависимостей, вся графика процедурная. Проект открывается в Android Studio
как есть.

## Что уже есть

**Ядро выживания**
- Вид сверху, ландшафтная ориентация, плавающий виртуальный джойстик
  (касание в любом месте экрана).
- Автоатака 4 видами оружия: **Дротики**, **Орбитальные клинки**,
  **Аура огня**, **Молния**. У каждого 5 уровней прокачки, до 4 оружий
  одновременно.
- Враги 5 типов (ходок, бегун, громила, танк, элита) с ростом сложности
  по минутам. Элита появляется раз в минуту и всегда дропает шмотку.
- Кристаллы опыта, уровни, экран выбора «1 из 3» (оружие/пассивки).
- 8 пассивных навыков: урон, скорость атаки, бег, здоровье, броня,
  магнит, область атак, опыт.

**Карта (главный акцент)**
- Бесконечный мир, генерируется чанками детерминированно от сида забега.
- **Сундуки** разбросаны по карте — подошёл и получил предмет.
- **Шрайны** трёх видов — стой в круге 5 секунд, чтобы захватить:
  - *Шрайн ярости* — +60% урона, +25% области (35 c);
  - *Шрайн ветра* — +35% скорости, +45% скорости атаки (35 c);
  - *Шрайн камня* — +80% брони, +25% HP, +50% магнита (45 c).
- **Статуи предков** — захват 9 секунд, дают **постоянный** +5% ко всем
  навыкам до конца забега.
- Пока идёт захват — на точку стягиваются волны врагов.

**Экипировка (Megabonk-стиль)**
- 5 слотов: талисман, броня, сапоги, амулет, кольцо.
- 4 редкости: обычный / редкий / эпический / легендарный — чем дольше
  забег, тем выше шанс редких вещей.
- Случайные статы по профилю слота (у сапог — скорость и магнит,
  у кольца — скорость атаки и урон, и т.д.).

## Сборка

Нужен Android Studio (или Android SDK + JDK 17):

```bash
cd android-game
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Либо просто открыть папку `android-game` в Android Studio и нажать Run.
Минимальная версия Android — 7.0 (API 24).

## Структура кода

| Файл | Что делает |
| --- | --- |
| `Game.kt` | Ядро симуляции: враги, оружие, опыт, захват точек, состояния |
| `World.kt` | Чанковая генерация карты: сундуки, шрайны, статуи |
| `Items.kt` | Генератор экипировки: слоты, редкости, статы |
| `Weapons.kt` | Баланс оружия по уровням |
| `Upgrades.kt` | Пул апгрейдов для экрана левел-апа |
| `Stats.kt` | Характеристики и баффы |
| `Entities.kt` | Игрок, враги, снаряды, подбираемое |
| `Renderer.kt` | Вся отрисовка: мир, сущности, HUD, оверлеи |
| `Joystick.kt` | Виртуальный джойстик |
| `GameView.kt` | Игровой цикл и ввод |

## Идеи на потом

- Мета-прогресс между забегами (валюта, разблокировка персонажей).
- Больше оружия и эволюции (комбо оружие + пассивка).
- Боссы на 5/10 минут, событийные зоны на карте.
- Звук и вибрация, спрайты вместо процедурной графики.
